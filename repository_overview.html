ii.
§ 01 · Repository purpose

A working example for a habit, not a finished product.

This project contains materials for a 45- to 60-minute workshop in FCUL's Intro to AI class. The workshop uses an agentic coding tool to build and review a baseline classifier for GitHub issue reports — small enough to fit a single sitting, sharp enough to expose every joint in the engineering loop.

The lesson is the loop itself: plan the work, prompt the agent, verify the result, review skeptically. The classifier is the working example used to teach that loop — not the deliverable, but the canvas.

§ 03 · Dataset

Three thousand issues, five rows of metadata.

The dataset comes from the NLBSE'24 issue-report classification task. Each row is one GitHub issue with columns repo, created_at, label, title, and body.

The CSV files are present locally, but the project documentation says they should be fetched from upstream rather than redistributed because the upstream dataset repository has no license.

viii.
§ 07 · Critical reading

What looks clean — & what needs care.

Looks clean

  1. The train and test splits are already provided, so a baseline model should use them directly.
  2. The dataset is balanced by label and by repository, which makes accuracy easier to interpret.
  3. There are no duplicate rows in either CSV.

Needs care

  1. The test file has 2 missing bodies; code should fill or handle null text.
  2. Some issue bodies are extreme outliers, including one training body over 200k characters.
  3. Many bodies contain HTML comments, Markdown code fences, logs, URLs, and non-ASCII text.
  4. Using repository names as features may inflate performance if the goal is to generalise to unseen projects.
ix.
§ 08 · Closing

A conservative baseline.

A conservative baseline would combine title and body, fill missing bodies with an empty string, fit a TF-IDF vectoriser only on the training split, train a simple classifier such as logistic regression, and report accuracy plus per-class precision, recall, and F1 on the provided test split.
